# 코인 거래소 수수료 비교: 국내 원화거래소 0% 경쟁과 해외 거래소 VIP 요율, 내 거래에 실제로 유리한 쪽 고르기

수수료는 거래소를 고를 때 가장 먼저 보게 되는 숫자다. 그런데 막상 비교해보면 "무료"와 "0.05%"와 "0.10%"가 뒤섞여서 뭐가 싼 건지 감이 안 온다. 어디는 전 종목 0%를 걸었고, 어디는 0.05%를 유지하고, 해외 거래소는 0.10%에 17단계 등급표를 붙여놓았다.

그래서 이 글에서는 숫자를 나열하는 대신 두 가지만 정리한다. 지금 국내외 거래소 수수료가 실제로 어디까지 내려왔는지, 그리고 내 거래 규모와 스타일에서 어느 쪽이 얼마나 싼지.

## 0.05%와 0.10%는 얼마나 차이 나나

먼저 체감부터 잡자. 1만 USDT어치를 사고팔 때 수수료는 이렇게 나온다.

- 0.05% 왕복(매수 0.05% + 매도 0.05%) → 약 10 USDT
- 0.10% 왕복 → 약 20 USDT
- 0% 왕복 → 0 USDT

한 번 거래에 10달러 차이다. 하루 한 번만 돌려도 한 달이면 300달러, 1년이면 3,650달러다. 여기서 0.04%, 0.058%, 0.09% 같은 숫자가 붙기 시작하면 계산이 복잡해지는데, 복잡해지는 지점이 바로 사람들이 비교를 포기하는 지점이다. 그래서 구조를 먼저 이해하는 게 낫다.

거래소 수수료는 크게 세 층으로 나뉜다.

1. **거래 수수료** — 실제로 사고팔 때 발생하는 비용. 메이커(지정가 대기 주문)와 테이커(즉시 체결 주문)로 요율이 갈린다.
2. **입출금 비용** — 암호화폐 입금은 대부분 무료거나 네트워크 수수료만 붙는다. 문제는 출금이다. 특히 국내 거래소에서 해외 거래소로 자산을 옮길 때 국내 쪽 출금 수수료가 먼저 나간다.
3. **숨은 비용** — 슬리피지, 선물의 펀딩비, 원화 예치금 이용료 같은 것들. 요율표에는 안 나오지만 실수익을 갉아먹는다.

## 국내 원화거래소 수수료 현황

2026년 하반기 국내 시장의 키워드는 "무료"였다. 코빗(현 디지털엑스)이 8월 24일부터 원화마켓 전 종목 거래 수수료를 1년간 무료화했고, 코인원도 8월 26일부터 수수료 무료 바우처를 발급해 전 종목을 0%로 돌렸다. 바우처는 30일 단위로 재발급가능하고 별도 자격 제한이 없다는 게 보도된 내용이다.

## 무료 수수료 뒤에 숨어 있는 것들

수수료 인하 경쟁을 볼 때 같이 봐야 할 항목이 몇 가지 있다.

- **이벤트 종료 조건**: "별도 공지 시까지", "1년간", "약 2주간"이 전부 다르다. 업비트의 BTC·USDT 마켓 0.05% 인하는 기간이 정해진 이벤트였고, 코인원 무료 바우처도 정책이 바뀌면 조건이 달라진다.
- **거래 방식 제한**: 무료나 우대 요율이 API 거래에만 적용되는 경우가 있다. 빗썸의 API 무료화, 업비트의 API 메이커 리워드(체결금액의 0.04%)가 그런 예다. 앱으로 직접 매매하는 사람에게는 적용되지 않는다.
- **출금 비용**: 국내 거래소에서 코인을 빼서 다른 곳으로 옮기면 출금 수수료가 붙는다. 수수료 0% 거래소로 갈아타도 자산 이동 단계에서 비용이 나가는 구조다.
- **원화 예치금 이용료**: 고팍스는 9월 16일부터 예치금 이용료율을 연 1.7%로 올렸다. 예치금 이자를 챙길지, 거래 수수료를 아낄지는 별개의 문제다.

## 해외 거래소까지 같이 봐야 하는 이유

국내 거래소만 비교하면 표가 짧게 끝난다. 그런데 실제로 수수료를 비교하는 사람들이 해외 거래소를 함께 보는 이유는 따로 있다.

- 국내 원화마켓에 상장되지 않은 종목을 거래하려면 결국 해외로 가야 한다.
- 선물·옵션 같은 파생상품 요율은 국내 원화거래소가 제공하는 범위가 제한적이다.
- 거래량이 일정 규모를 넘으면 VIP 등급제로 요율을 더 내릴 여지가 있다.

## 승급 조건은 세 갈래다

등급은 세 가지 기준 중 유리한 쪽으로 결정된다.

1. **30일 거래량**: 스팟(환전 포함) 100%, 주식 거래량 100%, 선물 거래량은 40%만 반영된다. 옵션과 CFD는 각각 20%, 10%다. 즉 현물보다 선물 쪽 계수가 낮게 잡혀 있다.
2. **14일 평균 GT 보유량**: VIP1이 50 GT, VIP5가 2,000 GT, VIP14가 150만 GT 수준이다. 거래를 거의 안 해도 GT를 들고 있으면 등급이 올라간다.

승급은 자동이고 30일 거래량으로 처음 승급한 경우 60일간 등급이 유지된다. 그 이후 유지 조건을 못 채우면 조정이 시작된다. 자산이나 GT 보유로 올린 등급에는 이 보호 기간이 적용되지 않는다는 점은 기억해둘 만하다.
